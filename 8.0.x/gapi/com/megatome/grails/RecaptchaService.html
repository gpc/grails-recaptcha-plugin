        • void cleanUp(java.lang.Object session)

          Cleanup resources associated with the session. This does have to be called, but not calling it will leave the recaptcha object in memory until the session expires.

          Parameters:
          session - The current session.

        • java.lang.String createCaptcha(java.lang.Object props)

          Creates HTML containing all necessary markup for displaying a ReCaptcha object. This method is most commonly called by the ReCaptcha tag library and not by other users.

          Parameters:
          props - Options for rendering, theme, lang, type, and tabindex are currently supported by recaptcha. The includeScript can also be specified and will override the global configuration setting.
          Returns:
          HTML code, suitable for embedding into a webpage.

        • java.lang.String createCaptchaExplicit(java.lang.Object props)

          Creates HTML containing all necessary markup for displaying a ReCaptcha object using explicit mode. This method is most commonly called by the ReCaptcha tag library and not by other users.

          Parameters:
          props - Options for rendering; lang, and loadCallback are currently supported by recaptcha.
          Returns:
          HTML code, suitable for embedding into a webpage.

        • java.lang.String createRenderParameters(java.lang.Object props)

          Create a JSON-like string containing parameters to be passed to the ReCaptcha JavScript object when using explicit mode. @return

          Parameters:
          props - Options for rendering; theme, type, tabindex, callback, expired-callback are currently supported

        • java.lang.String createScriptEntry(java.lang.Object props)

          Creates HTML containing the script tag definition necessary for displaying a ReCaptcha object. This method is most commonly called by the ReCaptcha tag library and not by other users.

          Parameters:
          props - Options for creating the tag. Only lang is supported.
          Returns:
          HTML code, suitable for embedding into a webpage.

        • boolean verifyAnswer(java.lang.Object session, java.lang.Object remoteAddress, java.lang.Object params)

          Verify a ReCaptcha answer.

          Parameters:
          session - The current session.
          remoteAddress - The address of the browser submitting the answer.
          params - Parameters supplied by the browser.
          Returns:
          True if the supplied answer is correct, false otherwise. Returns true if ReCaptcha support is disabled.
