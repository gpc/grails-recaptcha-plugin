        • boolean checkAnswer(java.lang.String remoteAddr, java.lang.String response)

          Validates a reCaptcha challenge and response. @return

          Parameters:
          remoteAddr - The address of the user, eg. request.getRemoteAddr()
          response - The response from the reCaptcha form, this is usually request.getParameter("g-recaptcha-response") in your code.

        • java.lang.String createRecaptchaExplicitHtml(java.util.Map options)

          Creates HTML output for creating an explicit recaptcha. The string response should be output on a HTML page (eg. inside a GSP). @return

          Parameters:
          options - Options for rendering. Only lang and loadCallback are supported here.

        • java.lang.String createRecaptchaHtml(java.util.Map options)

          Creates HTML output with embedded recaptcha. The string response should be output on a HTML page (eg. inside a GSP). @return

          Parameters:
          options - Options for rendering, theme, lang, type, and tabindex are currently supported by recaptcha. The includeScript can also be specified and will override the global configuration setting.

        • java.lang.String createRenderParameters(java.util.Map options)

          Create a JSON-like string that can be used to populate the recaptcha options when using explicit mode. @return

          Parameters:
          options - Options for rendering. Supports theme, type, and tabindex.

        • static java.lang.String createScriptTag(java.util.Map options)

          Create HTML output containing only the script tag required for ReCaptcha @return

          Parameters:
